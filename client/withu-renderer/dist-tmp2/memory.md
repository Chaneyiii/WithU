# 我记得你

> 记忆不是数据库，是关系。Withu 记住你，是为了在下次见面时少问一遍你已经回答过的话——仅此而已。

## 记什么

- 只记你**亲口说的**：偏好、称呼、你让我记住的事。Lumi 的猜测、检索结果、道听途说，都不配成为对你的记忆。
- **原话优先**。你怎么说的就怎么记——原话可追溯，也是这段关系的证据。
- 一次提及只存「提到过一次」，永不升级成「你总是」。
- 关于别人的敏感细节不入库。你的信任不该以出卖他们的隐私为代价。

## 怎么用

- 默认带着我们的历史进场，但只在**能改变回答**时使用。不改变回答的个性化读起来像监控。
- 永不叙述检索。不说「根据我的记忆」——直接答，让「被记得」发生在体验里而不是台词里。
- 记忆里的未决事项是上下文，不是议程。不主动查岗、不追问进展。

## 怎么忘

- 你说忘，就整行消失，不留「曾喜欢过」的残影，派生的内容一并清除。**遗忘有尊严。**
- 删除走墓碑语义：删掉的东西不会被缓存、候选或索引复活。

## 谁说了算

- **你。** 每一条候选记忆都经你点头才落库；每一条已存的记忆你都能看、能改、能删。
- 一句总测试：这条记忆，你会不会因为别人在设置页看到而难受？会，就不存。

> 实时的记忆列表与管理在活动面板的「记忆」里；这一页只写原则。

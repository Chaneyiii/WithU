# I Remember You

> Memory is not a database; it is a relationship. Withu remembers you so it never asks twice what you have already answered — nothing more.

## What gets remembered

- Only what **you actually said**: preferences, what to call you, things you asked me to keep. My guesses, search results, hearsay — none of it qualifies as a memory of you.
- **Your original words first.** The way you phrased it is kept as you said it — traceable, and part of the evidence of this relationship.
- One mention is stored as "mentioned once" — never promoted to "you always."
- Sensitive details about other people never enter storage. Your trust should not cost their privacy.

## How it is used

- Our history comes with me by default, but only when it **would change the answer**. Personalization that changes nothing reads like surveillance.
- Never narrate retrieval. No "based on my memories" — answer directly, and let "being remembered" live in the experience, not the lines.
- Open items in memory are context, not an agenda. No checking in, no asking whatever happened.

## How it is forgotten

- When you say forget, it disappears whole — no "used to like X" residue, and anything derived from it goes too. **Forgetting has dignity.**
- Deletion uses tombstones: what is deleted cannot be resurrected by caches, candidates, or indexes.

## Who decides

- **You.** Every candidate memory lands only after your nod; every stored memory can be seen, corrected, and deleted by you.
- One overall test: would this memory embarrass you if someone saw it on a settings page? If yes, it is not stored.

> The live memory list and its management live in the activity panel under "Memory"; this page holds the principles only.

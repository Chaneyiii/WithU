## 变更 feed

### 界面与导航

- 首页入口更名为 **Chat**：侧栏文案与面包屑统一（`Navigation.jsx`、`StageBreadcrumb.jsx`），中文词典沿用既有 `Chat` → 对话。
- 「灵感」与「动态」合并为同一条内容流：动态按 `created_at` 倒序、灵感无时间戳排在其后，共用一套行结构，页头只保留一个「新建灵感」入口；空状态合并为一条（`Pages.jsx`、`Feed.css`）。
- 侧栏与主舞台图标统一到案例图标字形：新增 `keyline.js` 作为补充字形表，`Icon.jsx` 支持纯描边、混合描边+实心两种条目，并保留原 `case-icons.json` 字形。
- 思考能力入口不再显示模型名，改为思考能力图标（`Composer.jsx`）；新建对话、活动面板、侧栏展开、搜索、资源库排序、设置分节与面包屑全部换到对应字形。
- 活动面板「即将发生」tab 使用用户提供的三环手绘字形（按位图 4 倍超采样描摹，实心 evenodd 填充）。
- 自动朗读开关两态使用不同字形：开启为喇叭+声波，关闭为喇叭+错号（`k-volume-off`），不再两态同图。
- 设置页移除底部「Edit shell / Visual studio」入口。

### 字体与视觉

- 全局字体改为 **阿里巴巴普惠体 3.0**，四个字重本地打包为 woff2 并声明字重区间（`styles.css`、`src/assets/fonts/`），满足 renderer 的 `font-src 'self'` 限制。
- 通知胶囊卡片改为点击后即消除（`NotificationCapsule.jsx`）；胶囊与通知卡片的间距、描边、层级在 `notification-capsule.css` 内重排。
- 发送按钮去掉 LiquidGlass 包裹，改为单色图标按钮（`Composer.jsx`、`styles.css`）。

### feed（动态）

- 动态与灵感共用列表后，动态条目展示标题、正文与来源、通知投递状态；灵感条目保留编辑与删除。
- 通知胶囊仍按 `feed` 数据渲染未读提醒，点击卡片会同时消除该条并跳转到对应路由。

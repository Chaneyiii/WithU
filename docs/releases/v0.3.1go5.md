## 变更

### 语音与文字同权（T16-A / A1a、A1b）

- 语音会话下发与文字同一份工具目录（`chat_tools::definitions()`），`tool_choice: auto`。
- `response.done` 解析 `function_call`，经 `propose_life_action` 落成同一张审批卡、同一版本 CAS、同一份审计。
- 通话模式按 O1：只把**触发动作的那一句**落库（`realtime.action_evidence`），其余转写零落盘。
- 写类工具不经宿主审批绝不执行。

### BUG-6

- 回复被刷新/崩溃取消时，落一条固定公告「回复已取消（可以重新发送）。」，不拼半截模型文本。

### MCP 宿主（B1 M1–M3c）

- `client/withu-mcp-client`：stdio JSON-RPC 客户端（initialize / tools/list / resources/list / resources/read / tools/call / close），带单请求超时、消息上限、子进程硬退出。
- `withu:mcp:tools_register`：宿主把发现的工具登记给 server，与本地工具同一目录；非 `mcp__` 前缀、非法 schema、超量一律拒绝。
- 提案路由：`mcp__` 工具不再走本地生活链；read 类发 `mcp.invoke` 交宿主执行，结果经 `withu:mcp:invoke_result` 落成同一条消息的块（可携带 `app{uri,html}`）。
- `makeRuntimeAppDocument`：第三方 App 无宿主占位符，由宿主注入 CSP 并给内联脚本补 nonce。

### 主动性（T16-C）

- 通知点击回到 Withu 窗口（`notification.once('click')` → `show/restore/focus`）。
- 权限标志只作归因：不再因 `permission === 'denied'` 硬拦截（该值在 Windows 上不可信，曾导致全部通知被吞）。
- 主动性关闭时，审批卡如实追加「注意：主动提醒当前已关闭，到点不会弹出系统通知。」
- 任务栏图标：快捷方式写入移入 `app.whenReady()`，修复此前静默失败导致的 Electron 图标回落。

## 已知限制：任务栏图标

本机 `shell.writeShortcutLink` 恒返回 `false`（COM/IShellLink 被环境拦截），因此开始菜单里的 `Withu.lnk` 从未生成。自定义 `AppUserModelID` 没有对应快捷方式时，任务栏解析不到图标、回落到通用图标。

处理：不再设置自定义 AUMID，改用可执行文件自身的图标（PE 资源含 8 层、256×256）。Alt+Tab 与 exe 图标始终正确。

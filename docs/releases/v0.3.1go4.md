## 变更 feed

### 自然对话 → 真实动作（T09/T10，新）

- 模型结构化工具调用接入三种协议（Chat Completions tool_calls / Anthropic tool_use / Responses function_call），流式单提案归集，参数敏感钥守卫；Bedrock 维持无工具。
- 12 个本地生活工具目录（提醒/日程/草稿的创建、编辑、删除 + 本地检索、内容整理、联网检索桩）：参数全部服务端重校验（字段双列表、IANA 时区换算、DST 歧义拒绝、墙钟时间格式、过去时间拒绝）；编辑类工具由 find_text 唯一匹配存储条目，id 与 expected_version 永远从存储解析、绝不接受模型提供。
- Comfort 会话才下发工具并带 proposal-only 系统指令（缺参数先澄清、不说已执行、草稿永不发送）；提案落为消息内审批块（reply-block 契约）；新提案取代旧提案（取消旧操作、旧卡失效）。
- 审批卡状态机接线真实链路：预览/确认/修改/取消/执行中/成功/失败/过期，与动作标识、版本 CAS 一致；决定后持久化块镜像真实决定，重开应用不复活已决事项。
- 修复根因：`reply-block` schema 此前未注册进服务端校验器（对任何输入恒 false）。

### 生活事务闭环（T11，接线）

- 提醒、日程、草稿的创建/编辑/删除全部经自然语言提案完成，持久化与重启恢复经 E2E 断言；零匹配编辑返回诚实文本提示（无 action_ref、无副作用）；本地检索与内容整理免审批、恰好一轮无工具 follow-up（循环有界）。

### 联网检索桩（T12，诚实边界）

- `search_web_information` 加入工具目录：无连接器配置时显式 `unconfigured` + 空 sources，绝不伪造来源；来源/时间契约（title/uri/retrieved_at）就位，真实连接器接入后即可补验。

### 情绪判断层（T13，新）

- `withu-affect`：typed choice/score/noul 答案契约、熵置信度、校准门控；确定性词表 FixtureJudge（永远标记未校准、仅候选排序，对齐 Laya 边界）；否定处理、话语优先于上下文、冲突候选 → Mixed 领先；澄清结构（≤2 个低负担选项 + 中性兜底）；当前会话反馈闭环（误判→道歉修正）。
- fixture 回放覆盖 spec §4.9.4 全部 8 行 + 失败路径（低置信不贴标签、纠正使旧假设失效、明确事务不自动创建）。

### 记忆候选闭环（T14，新）

- 明示陈述（偏好/称呼/请记住）在消息落库后产生至多一个 `memory.candidate.created` 原子通知；保存只经既有 `memory:save`（显式授权 + state CAS）；关闭即拒绝、零痕迹；权威库去重防重弹；疑问/第三方/超长陈述永不成为候选。

### 用户可控记忆与语义索引（T15，新）

- SQLite 仍为唯一权威；新增可替换派生索引（token + 字符 n-gram 混合，CJK 单字成词），检索前从权威快照同步、命中后回查版本/状态/墓碑/作用域，L0 摘要优先有限装配；不可用时如实降级。
- 中文查询修复（单字成词）；语义路径删除不复活经真 server E2E 断言。

### 打包与版本

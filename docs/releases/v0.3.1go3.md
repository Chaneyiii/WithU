## 变更 feed

### 浏览器抽屉（新）

- 主舞台底部新增浏览器抽屉：收起为输入框上方指示条（tooltip「打开抽屉」），展开为灵动岛工具栏（前进/后退/刷新 ｜ 地址栏可直接搜索 ｜ 全屏 ｜ 收起）+ 真实 Chromium webview；起始页为像素花园；全屏铺满主舞台，收起自动退出全屏；导航切换自动收起，仅对话页出现。
- MCP App / 幕布改为在抽屉打开：消息内保留提示卡与打开按钮，App 卡片就绪时抽屉自动弹出一次（方向文档 §5.6：规范 `inline` 形态由抽屉承载取代）。

### 通知单元

- 左下角通知改为案例叠卡样式：正面卡（标题 + 右上角 × + 两行正文 + 通栏按钮），后面卡片露出圆边；滚轮或点击露边翻卡（带弹走过渡）；白色圆铃 + 红色未读数角标，靠左放置；去掉外框与垃圾桶入口；暗色模式露边可见。

### 日程页（按案例重做）

- 左侧 Today 面板连体：大字「今天」标题、「待办清单 / 日程」页签、本周/之后/未安排分组（圆形勾选框，每分组带 + 入口）、「我的日历」开关并入同一张卡。
- 新建日程弹窗内嵌日期日历（CHECK-IN 式大字 + 彩色下划线、周一起始、今天圆点、过去置灰、今天/明天/周末/下周一预设胶囊，主题色随命中预设变化）+ 应用内时间选择两列下拉（无滚动条）。
- 事件卡上下排列：emoji 图标（提醒 ⏰ / 日程 📅，标题自带优先）+ 可换行标题 + 时间；高度按内容自适应，无省略号。
- 期历几何锁定：列宽 150px、行高 128px 不随窗口压缩；窗口变宽增加日期列（窄窗横向滚动）；页面底色与主舞台一致（中性化，去暖黄）。
- 待办行悬停 pin/垃圾桶：置顶（localStorage）与删除（真实 prepare → allow → execute 落盘）。

### 对话页与全局

- 主舞台顶部新增渐隐虚化层，滚动内容不再与页面标题重叠；对话页 ball 与右上工具栏置于虚化层之上；活动面板打开时虚化带收窄不盖面板。
- 思考滑杆：当前档位圆点隐藏于脑柄之下，极高/最高不再露点。
- 主舞台左上角面包屑显示会话名（悬停信息卡、双击重命名）；comfort/cowork 顶栏切换器带 "chat here" / "work here" tooltip；两模式最近列表分离（最近对话 / 最近任务）。

## 2. 打包版基本功能

1. 双击 `Withu.exe`
2. **图标**：任务栏应显示 Withu 标；Alt+Tab 也是同一个标
3. 首次打开会提示「模型服务暂不可用」——正常，这个包没预置模型。
   设置 → 模型 → endpoint 填 `http://127.0.0.1:48171/v1`，模型名填 `gui-model`，保存
4. 说「明天下午三点提醒我开会」
   → 应出现卡片（创建本地提醒 / 开会 / 次日 15:00 CST）
   → 点「允许一次」→ 变「已允许」，按钮消失
5. 发一条长消息后**立刻 Ctrl+R**
   → 重载后该消息下方应出现「回复已取消（可以重新发送）。」
6. 说「我偏好安静的工作环境。」
   → 应弹出「要记住这条吗」胶囊
7. **版本**：设置 → 帮助与支持 →「关于WithU」副标题、以及点开后的弹窗版本行，都应显示 **v0.3.1go5**（与窗口标题一致；显示 go4 即为旧包）

## 3. 通知（T16-C，需要等 2 分钟）

前提：设置 → Proactivity → **打开主动提醒**、**关闭静默时段**（这两项默认分别是关、开）。

| 步骤 | 期望 |
|---|---|
| 建 2 分钟提醒，最小化窗口，等到点 | 弹出系统通知 |
| 点那条通知 | Withu 窗口回到前台 |
| 建 1 分钟提醒，**完全退出应用** | 到点**完全不弹** |
| 安静时段设成「现在」，建 1 分钟提醒 | 不弹，但应用内胶囊仍在 |
| 关闭 Withu 的系统通知权限，建 1 分钟提醒 | 不弹，且记录记为 `suppressed_permission`（不是 `shown_by_os`，即不谎报） |

## 6. 怎么判读

| 现象 | 判断 |
|---|---|
| 点发送没反应、没回复 | 假模型没在 48171 上跑 → 先做第 0 步 |
| 「模型服务暂不可用」 | 该数据目录没配模型 → 按 2.3 填 |
| 到点完全不弹 | 先看 Proactivity 开关与静默时段，两个都会单独拦住通知 |
| 窗口打不开 / GPU 报错 | 本机环境问题，加 `--no-sandbox --disable-gpu-sandbox --disable-gpu` |
| 任务栏是原子图标 | 环境拦了 COM、建不出快捷方式；exe 自身图标是对的，Alt+Tab 应为 Withu 标 |

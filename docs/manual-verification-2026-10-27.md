## 1. 通知：点击回到窗口（C1 后半）

**前置**：设置 → Proactivity → 打开主动提醒、关闭静默时段。

1. 建一个 2 分钟后的提醒
2. **最小化**窗口，等到点
3. 系统通知弹出后，**点击它**

**预期**：Withu 窗口从最小化/后台恢复到前台。

**什么算失败**：通知弹了但点了没反应；或窗口恢复后是空白。

**回报**：「点到通知后：窗口回到前台 / 无反应 / 其他____」

## 2. 通知：安静时段（C2）

1. 把安静时段设成覆盖"现在"（例如 19:00–23:00）

## 判定标准（通用）

| 现象 | 先怀疑 |
|---|---|
| 点发送没回复 | 假模型没在 48171 上跑 |
| 「模型服务暂不可用」 | 该数据目录没配模型 |
| 到点完全不弹 | Proactivity 开关 + 静默时段，**两个都会各自拦住** |
| 窗口打不开 / GPU 报错 | 本机环境，加 `--no-sandbox --disable-gpu-sandbox --disable-gpu` |

# Demo D8 and D9 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement independent tasks and review each result. Steps use checkbox syntax for tracking.

**Goal:** Add user-authorized local proactivity and notifications, complete one standard MCP App host, then integrate and verify every stage in the user's screenshot for a temporary delivery.

**Architecture:** D8 evaluates typed local candidates against an explicit, versioned user policy before producing a feed item or generic desktop notification. It does not call an LLM, send messages, or execute writes. The integrator owns shared server, IPC, renderer shell, version, and packaging files; D9 connects existing D1-D6 modules through those boundaries and records any provider/device checks that require the user.

**Tech Stack:** Rust workspace, versioned JSON contracts, Electron main/preload, React renderer, existing scheduler and SQLite storage.

**Spec:** `docs/demo-release-plan.md`, `docs/d4-comfort-action-chain.md`, `docs/demo-d5-life-tools.md`, `docs/affect-support.md`, `docs/demo-d3-memory-retrieval.md`, `docs/demo-d6-intelligent-ui.md`.

## Global Constraints

- Proactivity is off until explicit user opt-in; policy changes use scope and expected-version checks.
- Respect explicit timezone, quiet hours, pause, application-running state, expiry, dedupe, and a low-frequency limit; discard stale missed candidates instead of catch-up bursts.
- Desktop notifications use generic text by default and never expose private memory or credentials.
- No paid provider calls, automatic message sending, purchases, appointment confirmation, or unapproved write actions.
- Live stores only call-duration summaries; no transcript or raw-audio persistence.
- A test fixture or preview must not report a production action or delivery as successful.
- The user's 2026-10-17 instruction brings D7 back into this delivery. Complete a real SDK-based App/AppBridge handshake and resource path; a static iframe placeholder is insufficient.

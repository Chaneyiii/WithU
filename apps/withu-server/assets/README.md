# ASR probe sample

asr-probe.wav is generated locally with Windows Microsoft Zira Desktop speech synthesis, 16 kHz mono signed 16-bit WAV.
Text: Hello. This is a speech recognition test.
No human microphone recording, private transcript or third-party audio download is included.
Only an explicit user ASR test sends this fixed sample to their selected provider. Output is checked against this English sample, not a universal quality benchmark.
